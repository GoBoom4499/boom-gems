# Boom Gems

Three games in one self-contained HTML file, by GoBoomTV.

- **Boom Gems**: match-3 with Classic, Blitz, Extreme, Boss Battle, Pointers, Challenge, Puzzle, Plus, Relax, Boom Lab, Troubleshoot, Free-for-all, INSANE 100, Daily Boom, Boom Run (relics) and Challenge a Friend (share codes). Standard and Twist versions.
- **Gem Roll**: Zuma-style. Adventure, Zen, Blitz, Extreme, Pointers, Challenge, Boss Battle and Daily.
- **Boom Pegs** (working title): Peggle-style, with bar pegs, free balls and pet powers.

Current version: **v0.36.5a**. The full history is in the in-game Update History.

## Run it
Open `index.html` in a browser. There is nothing to build.

## Notes
- The Leaderboard and the shared Roadmap use the Claude artifact database, so on a plain web host they fall back to this device only.
- Versions use `a` = alpha, `b` = beta, `rc` = release candidate.
